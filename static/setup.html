Connect OuthMan once, then manage your agents with a verified account.

  1. Create the OuthMan appIn OuthMan, create a SysMan app and save its app ID and secret. Assign the app and your approved account to the same access group. Allow the SysMan backend IP in OuthMan’s API allowlist.
  2. Unlock this setupRun this command on your Raspberry Pi, then paste its setup token into the form.docker compose exec sysman python3 setup_admin.py token
  3. Link, then sign inAfter saving, link your existing OuthMan account. Generate a new six-digit code for the following sign-in.

The setup token proves access to your SysMan host. It is separate from your OuthMan app secret and user password.
